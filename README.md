# Project SCI AID by the NeuroRobotics Laboratory at the University of Utah

## Voice-Controlled Prototype of a 2-DOF Assistive Robot Arm for Spinal Cord Injury Patients

## Overview

This project aims to provide a solution for patients with spinal cord injuries by developing a **Voice-Operated 2 Degree of Freedom (2 DOF) Robot Arm With Impedance Control and Series Elastic Actuators**. The primary goal is to empower users to control the position and actions of the robot arm through voice commands, offering them greater independence in performing various daily tasks, while ensuring safe interaction via impedance control and series elastic actuators.

## Features

- 2 DOF: Enables wrist flexion and rotation motion for grasping objects and changing their orientation.
- Voice Control: Simple commands like "open" or "close" allow for effortless gripper interaction.
- Impedance Control: Ensures precise the interactions are safe by limiting contact forces.
- Series Elastic Actuators:
- Underactuation: The robot has passive joints that make it easily reconfigurable to reach new workspaces.
